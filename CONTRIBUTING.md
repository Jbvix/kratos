# Contributing to KRATOS

Thank you for considering contributing to KRATOS.

## Preferred Contributions

- Synthetic maritime scenarios
- Generic failure modes
- Mathematical engine improvements
- Documentation
- Validation cases
- Reproducible notebooks
- Educational examples

## Do Not Submit

- Real vessel names
- Company names
- Real operational logs
- Serial numbers
- Proprietary alarm limits
- Internal reports
- Sensitive industrial information

## Commit Convention

- `docs:` documentation changes
- `feat:` new modules
- `fix:` corrections
- `data:` dataset updates
- `release:` release preparation
- `refactor:` structural improvements
